As of the September 2026 release, we have added two new datasets: CCSS Therapy-Related Mutational Signatures in Subsequent Neoplasms and Genomic Sequencing of Pediatric Cancer Cases (CMRI/KUCC). We have also updated the Molecular Characterization Initiative dataset with the latest data for currently enrolled participants, added treatment data for more participants in the NCI-COG Pediatric MATCH Precision Medicine Clinical Trial, and updated the widget organization and dataset description for Open Pediatric Cancer (OpenPedCan) Project v15. Please visit the [Dataset Updates](dataset-updates) section for more information.

Regarding functional updates, we have added a Web API link to the REST API and addressed security vulnerabilities. The About page was modified with an updated link to the CCDI Explore Dashboard. We also fixed bugs in page formatting and back navigation from the dataset view.
