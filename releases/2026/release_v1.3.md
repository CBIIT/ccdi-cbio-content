With the latest release, we have added one new dataset: PedMATCH. In addition, we have updated the Molecular Characterization Initiative dataset with fresh clinical and genomic data from more participants. We have also included links to PubMed for each dataset. See the [Dataset Updates](dataset-updates) section for more information.

We have also made multiple changes to the underlying codebase. We have upgraded to cBioPortal [frontend version 6.3.6](https://github.com/cBioPortal/cbioportal-frontend/releases/tag/v6.3.6) and [backend version 6.4.1](https://github.com/cBioPortal/cbioportal/releases/tag/v6.4.1), added a banner with privacy and security notices, and addressed security vulnerabilities.
